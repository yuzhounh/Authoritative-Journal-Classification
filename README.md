# 权威期刊分类系统 (Authoritative Journal Classification)

## 项目简介

本项目是一个基于Python的权威期刊分类系统，基于中科院JCR分区表和JCR影响因子数据，自动计算权威期刊三级分类，并生成分学科的期刊分类报告。

## 数据来源

本项目的原始数据来源于 [hitfyd/ShowJCR](https://github.com/hitfyd/ShowJCR) 项目，该项目提供了：
- 中科院分区表升级版（2025、2023、2022）
- JCR影响因子数据（2023、2022、2021、2020）
- 国际期刊预警名单（2025、2024、2023、2021、2020）
- CCF推荐国际会议和期刊目录（2022）
- 计算领域高质量科技期刊分级目录（2022）

## 功能特点

- 📊 **数据整合处理**：整合中科院JCR分区表和JCR影响因子数据
- 🎯 **权威期刊分级**：基于期刊排名和分区统计，自动计算一级、二级、三级权威期刊分类
- 📚 **学科分类处理**：按照21个学科大类进行期刊分类和统计
- 📈 **影响因子匹配**：通过ISSN/eISSN自动匹配期刊影响因子数据
- 📄 **报告生成**：自动生成分学科的详细期刊分类报告

## 数据文件说明

### 输入数据
- `FQBJCR2025-UTF8.csv` - 中科院JCR分区表2025年版（主表）
  - 包含期刊名称、ISSN/eISSN、大类分区、小类分区等信息
  - 数据格式：`Journal,年份,ISSN/EISSN,Review,OA Journal Index（OAJ）,Open Access,Web of Science,标注,大类,大类分区,Top,小类1,小类1分区...`
- `JCR2024-UTF8.csv` - JCR 2024年影响因子数据
  - 包含期刊ISSN、影响因子、分区排名等信息
  - 数据格式：`Journal,ISSN,eISSN,Category,IF(2024),IF Quartile(2024),IF Rank(2024)`

### 输出数据
- `FQBJCR2025-QWQKFJ-UTF8.csv` - 包含影响因子和权威期刊分级的完整数据表
  - 在"Web of Science"和"标注"列之间插入"影响因子"列
  - 在"Top"和"小类1"列之间插入"权威期刊"列（一级/二级/三级）
- `Disciplines/` - 按学科分类的期刊数据文件夹
  - 格式：`Disciplines/FQBJCR2025-{学科名}-UTF8.csv`
  - 包含21个学科的详细期刊分类文件，按排名排序

## 权威期刊分级算法

本系统基于中科院JCR大类分区实施三级权威期刊分类：

### 分级规则

**一级权威期刊**
1. 中科院JCR大类分区一区期刊
2. 中科院JCR大类分区二区前50%（含50%）期刊

**二级权威期刊**
1. 中科院JCR大类分区二区后50%期刊
2. 中科院JCR大类分区三区期刊

**三级权威期刊**
1. 中科院JCR大类分区四区期刊

## 使用方法

### 运行程序
```bash
python authoritative_journal_classification.py
```

### 输出结果
程序运行后将生成：
1. 总的权威期刊分级表：`FQBJCR2025-QWQKFJ-UTF8.csv`
2. 分学科的期刊分类文件：`Disciplines/FQBJCR2025-{学科名}-UTF8.csv`
3. 运行日志：控制台输出格式示例
```
处理大类：历史学
该大类共有 778 本期刊
```

## 核心功能模块

### 1. 数据预处理
- ISSN/eISSN分离处理
- 期刊分区信息解析
- 影响因子数据匹配

### 2. 分级算法
- `calculate_authority_level()` - 基于中科院JCR分区的权威期刊三级分类计算
- `extract_rank_from_partition()` - 从分区字符串提取期刊排名（如"4 [625/778]"→625）
- `extract_zone_from_partition()` - 从分区字符串提取分区号（如"4 [625/778]"→4）
- `extract_total_from_partition()` - 从分区字符串提取总数（如"4 [625/778]"→778）

### 3. 报告生成
- 分学科统计报告
- 权威期刊分级统计
- CSV格式数据输出
